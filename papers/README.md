# Research paper workspaces

*Author: [Artur Sepp](https://github.com/ArturSepp)*

Software: [factorlasso](https://github.com/ArturSepp/factorlasso).
Citation: [CITATION.cff](https://github.com/ArturSepp/factorlasso/blob/main/CITATION.cff).

All paper workspaces are retained privately and excluded from the current source
tree in Git. Only this availability index and the paper policy are tracked.
The next package release is deferred until the forecasting draft is finished.

| Workspace | Availability |
|---|---|
| `sign_pooling_2026` | Forecasting manuscript and active replication retained locally and ignored; obsolete code preserved in a verified private backup |
| `jss_2026` | Entire workspace retained locally and ignored |
| `exposure_budget_floor_2026` | Current draft and analytical replication retained locally and ignored; OP's local `data_export_for_exposure_budget_floor_2026` supplies static production CMA inputs |
| Former `prior_targets_2026` workspaces | Removed from the active FL and OP trees; historical material retained in verified external backups |
| Other or future papers | Local and ignored until explicitly approved |

Each paper uses `paper/`, `drafts/`, `presentations/`, `private/`, `replication/`
and `agents/` as needed. Local directories are not represented by tracked
placeholders. The [paper contract](AGENTS.md) sets preservation, publication and
verification rules. Future publication requires a new maintainer decision and an
explicit inventory. Earlier public commits and historical archives remain
available in their original form. Untracking does not erase that history.

See [research papers and replication](../docs/scientific-replication.md) for
citation metadata and the distinction between public teaching examples and
paper reproduction. Papers are excluded from the Python wheel and source archive.
